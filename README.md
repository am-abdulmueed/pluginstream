**PluginStream** is a lightweight, high-performance Android application framework designed to offer custom modular extensions and built-in interactive HTML5 gaming experiences powered by PlayGama. Built with Kotlin and modern Android architecture guidelines, it emphasizes speed, privacy, and seamless navigation.

---

## 📖 Overview
PluginStream is built as a modular application container. It allows users to run local web-based games, manage custom modules, and organize digital web resources efficiently without unnecessary battery or data overhead.

## 🚀 Key Features

### 1. Modular Engine
* **Add-on Framework:** Seamlessly loads modular interface configurations.
* **Auto-Sync:** Keeps configurations updated locally.

### 2. Built-in HTML5 Games Dashboard
* **PlayGama Integration:** Access smooth, lightweight web games directly within the app without extra downloads.

### 3. Performance & Privacy First
* **Zero Personal Tracking:** No login required. User settings remain on the local device.
* **Optimized Playback & WebView:** Fast loading speeds with low memory usage.

---

## 📝 Requirements
- **Android Version:** Android 7.0 (Nougat) or higher (API 24+)
- **Storage:** Minimum 50MB free space.
- **RAM:** 2GB RAM recommended.

---

## 🛠️ Architecture & Tech Stack
- **Language:** 100% Kotlin
- **UI Architecture:** Android Jetpack, Material Design 3
- **Image Loading:** [Coil](https://github.com/coil-kt/coil)
- **HTML/Data Parsing:** [JSoup](https://jsoup.org/)
- **Networking:** [NiceHttp](https://github.com/Blatzar/NiceHttp) / OkHttp
- **Crash Analytics:** Firebase Crashlytics
